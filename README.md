# Pilotfish

Intentional, context-first tools for human-led AI collaboration.

Pilotfish helps turn code, notes, and project context into stable references for AI-assisted work.


# Layers


- Service memory: 
  - 長期互動傾向 / behavioral prior
  - 定時透過 discussion 的方式進行校正
- Project context: 明確世界狀態 / source of truth
  - save in the project
- Inline action: local intent / colocated instruction
  - assign with the inline block or comment
- Skill:
  - reusable method
  - procedural abstraction
- Prompt:
  - invocation / pointer
  - Directly invocate the inline action
